## 2026-08-26 — the Windows 98 shell stays

f-keys.com keeps the file-manager interface. It is not decoration and it
is not nostalgia: the folder tree IS the catalogue's information
architecture, twenty-six products sorted the way a file manager sorts
them, and it degrades to a phone without breaking. A neutral agency
redesign would cost the one thing a solo builder has that an agency
cannot buy, and would not have answered any objection a client actually
raises.

What reads as unprofessional is never the chrome. It is a homepage that
said twenty-two products when there were twenty-six. That is fixed, and
derived from the catalogue now so it cannot say a number again.

Next: product images and screenshots. The shell is fine; the shelves
are bare.
