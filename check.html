Checks

Tools that compare a thing to what it claims: publication records, interfaces, prompts, color vision, and this site's own builds.

NameType StatusDescription

📡Prompt CheckServiceNeeds setupSend a system prompt and it is run against a live model: which rules hold, which break, and the rewrite that holds.
📡Security CheckServiceNeeds setupYour site's security headers read against the OWASP standard: what's exposed, and the fix applied.
