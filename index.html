What this is

F-Keys Creative LLC is a one-person software studio in Punta Gorda, Florida. The website service above is the thing that is for sale to local businesses. Everything below it is the rest of the work: applications, browser games, Python packages, measurement tools and published research, most of it free to use and all of it built here.

If you arrived from a link to one particular thing — a paper, a package, a game — it is in the catalog below, which holds six sections, sorted the way a file manager sorts them. Its own page carries its license, its terms and its price. Nothing is assumed to match the last one.

And yes, the interface is deliberate. It is a Windows 95 file manager because the catalog is a list of files and folders and that is the honest shape for it, not because the site is old. Everything on it was built this year.
