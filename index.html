How this site is checked

The checks that are for sale above are the ones this site runs on itself before every build: every text color computed against its background to the WCAG 4.5:1 floor, a minimum type size, and an accessibility audit over the WCAG 2.2 A and AA criteria that can be decided from the page. Every page here passes all of them. Status reports what is running and what it measured, from the same file the site is built from.
