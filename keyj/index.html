CAPABILITIES

GLOBAL CAPTURE

Turn it on and Key-J hears your keys everywhere — Notepad, Chrome, a game. Type an email, compose a song by accident.

LIVE STAFF

Notes land on a staff in real time, in order, and the session picks up exactly where you left it.

MELODY LOCK

Capture a sequence and hold it, so you compose against a fixed line instead of improvising every pass.

REMAPPABLE KEYS

Click any key to reassign its note. Switch scales — major, minor, blues — and shift the whole board by an octave.

SIX PLAY STYLES

Normal, staccato, vibrato, tremolo, arpeggio, legato — plus four waveforms and attack, release, and glide on sliders.

WAV EXPORT

Export the whole session as a WAV file. No DAW anywhere in the process.

THE DESKTOP BUILD

The browser version runs right here. The Electron build adds the system tray and global capture, which is what lets it listen outside its own window.

  1. Clone or download the keyj/desktop folder
  2. npm install
  3. npm start
  4. Toggle Global Capture on

Windows 10 or 11, Node 18+. Global capture may need an administrator terminal. Mac and Linux build targets are configured.
