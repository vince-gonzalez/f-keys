CAPABILITIES

SEARCH BY ZIP

Pick a category and a ZIP code. Results are businesses with no website listed against them.

FILTERS THAT MATTER

Exclude chains, set a minimum review count and rating, or narrow to high-value results only.

CSV EXPORT

Download the list, or have it saved automatically after every search.

SEARCH HISTORY

Past searches persist with session stats, so you don't re-run the same territory by accident.

DESKTOP OR BROWSER

Ships as an Electron desktop app and as a React browser build.

YOUR OWN KEY

Runs on your Google Maps API key, so the quota and the data are yours.

WHAT YOU NEED

  1. Node.js 18 or newer
  2. A Google Maps API key from the Cloud console
  3. npm install
