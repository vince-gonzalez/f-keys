LeadSeer

Find who is not online yet.

LicenceMIT
RuntimeNode 18+
NeedsGoogle Maps API key
BuildsElectron desktop, React browser

What it does

Every town has businesses doing fine without a website. LeadSeer asks Google Places which ones they are, filters out the chains, and hands you the list.

Filters

Search by category and ZIP. Exclude chains, set a minimum review count and rating, or narrow to high-value results. Export to CSV, or save automatically after every search. Past searches persist with session stats.

It runs on your own API key, so the quota and the data are yours.
