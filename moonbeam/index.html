MOONBEAM

A LOTTERY TICKET
THAT HUMS.

A Bitcoin miner on a chip that costs less than dinner. Moonbeam will almost certainly never win anything, and that isn't the point — it's a small machine that teaches you exactly what mining is by doing it on your desk.

BUILD ONE

What "lottery-inspired" means

A solo miner this size has odds against it that are difficult to describe without a lot of zeroes. Moonbeam is built to be understood and enjoyed, not to earn. Treat any other outcome as a surprise.

WHAT'S IN THE BOX

OPEN FIRMWARE

The whole miner, readable. If you want to know what SHA-256 actually is, this is a version small enough to follow end to end.

WEB DASHBOARD

Watch hashrate and status from a browser on your own network.

HARDWARE DESIGN

The build is documented, based on an ESP32 — cheap, common, and forgiving of a first attempt.

PRINTABLE ENCLOSURE

An STL for the case, so it ends up looking like an object rather than a board with wires coming out of it.
