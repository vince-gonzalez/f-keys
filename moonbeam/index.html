Moonbeam

Finds the NerdMiners on your network. One pip install, no dependencies, and it tells you what is actually out there rather than what you think you plugged in.

Install itSource

1.0.0 · pip install moonbeam-miner · Python 3.8+ · MIT · zero dependencies

What it does

Sweeps your subnet for ESP-Miner and AxeOS devices, NerdMiner and Bitaxe and relatives, and reads their vitals in a terminal. Whatever answers is remembered, so the next run just polls them.

pip install moonbeam-miner
moonbeam            the miners it knows, polled now
moonbeam scan       sweep the subnet
moonbeam watch      refresh until you stop it
moonbeam show ip    everything one miner reported

A dash means the miner did not say

It does not mean zero, and it is never a plausible number standing in for one that never arrived. The summary counts how many devices declined to report rather than quietly averaging them in.

Standard library only, so the install cannot fail on someone else's package.
