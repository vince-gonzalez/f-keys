Modulign Standard: Automated Classifier Certification Framework

Vince Gonzalez · ORCID 0009-0005-3640-014X · 2026-04-13 · Technical note · CC-BY-4.0

Read the PDF DOI: 10.5281/zenodo.19559602 All papers

Abstract

The Modulign Standard v3.0 permits automated systems (%AUT) to produce classifications, including ^EVID-grade classifications, provided domain competence requirements are met.  Version 3.0 does not specify how an automated system achieves or demonstrates competence certification.  This appendix establishes that framework.
