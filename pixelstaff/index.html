CAPABILITIES

PIANO ROLL

A 96-row grid you draw on directly. Draw, erase, extend a note, or clear the board.

CHANNELS & WAVEFORMS

Separate channels, each with its own waveform, the way the chips it sounds like actually worked.

TRANSPORT

Play, stop, rewind, and set tempo in BPM while you write.

WAV EXPORT

Render the track to a WAV file and name it on the way out.

RINGTONE EXPORT

Export straight to a ringtone file you can drop into iTunes and put on a phone.
