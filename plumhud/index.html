PLUMHUD

WATCH THE FLEET.
NOT THE SCREEN.

A miner fleet monitor that runs as a borderless overlay on top of whatever you're already doing. It polls every rig at once, keeps the history, and tells you the moment one stops earning.

$ python plumhud.py
✓ subnet scan — 254 hosts in 2s
✓ 20 miners polled concurrently — 2.5s
! rig-07 offline → Discord alert sent
GET PLUMHUD

CAPABILITIES

ASYNC POLLING

Every miner is polled concurrently, so twenty rigs take about two and a half seconds instead of most of a minute one at a time.

ALERTS THAT REACH YOU

Rules for offline rigs, hashrate below a floor, temperature above a ceiling, and reject spikes. Delivered to Discord or Telegram, with a cooldown per rule.

LOCAL ANALYTICS

Every poll is written to a local SQLite database with 30-day retention and auto-pruning, so you have history rather than a snapshot.

OVERLAY HUD

Four display modes — ring, bar, spark, grid — with an opacity slider from ghost to solid. Double-click to cycle.

SUBNET SCANNER

Finds the rigs for you. A parallel scan covers 254 hosts in roughly two seconds.

COMMAND CENTER

Miners, analytics, alerts, skin, and settings, with five presets and per-metric toggles for hash, temp, shares, and IP.

RUNNING IT

  1. Python 3.10 or newer
  2. pip install aiohttp requests Pillow matplotlib pystray
  3. python plumhud.py

A smaller install without aiohttp also works — it falls back to a threaded poller rather than refusing to start.
