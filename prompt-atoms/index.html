Prompt Atoms

Public prompt libraries reuse the same instructions — “Only output Markdown,” “Do not give warnings” — across unrelated tasks, and some of them contradict each other. This dataset pulls two public corpora apart into the recurring instructions, types each to a slot, counts how widely each is used, and maps the pairs that cannot both hold.

Atoms — CSVConflicts — CSVDatasheetCite — Zenodo

257 atoms · 32 conflicts · 195 public templates · CSV + JSON · CC BY 4.0 · DOI

How it works

  1. Pull the libraries apart into atomsFabric (265 task patterns, MIT) and prompts.chat (2,425 prompts, CC0) are reduced to 257 distinct instructions, each with the phrasings observed and how many prompts use it.
  2. Type each to a slotEvery atom is a role, a method, a check, an output rule, or a first-reply rule, so a prompt reads as structure rather than prose.
  3. Census the conflicts32 pairs cannot both hold — bulleted versus numbered, Markdown versus CSV, ten items versus twenty — each with the reason it clashes.
