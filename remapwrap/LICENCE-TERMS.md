# RemapWrap licence terms

**DRAFT — not published, and it contains a decision only you can make.**

The Contract Colossus named the word that decides a future dispute:
**perpetual**. Your code already implements one answer, and if a sales page
ever says something different, the page loses. So this writes down what the
code actually does, and marks the one place where you have to choose.

---

## Free

RemapWrap is free to use, forever, with no account, on as many of your own
computers as you like. The free version includes:

- unlimited keys, unlimited profiles, unlimited pages
- free placement, any shape, any size
- every command RemapWrap can carry out
- two phones connected at once

Nothing in that list will ever move behind a payment. It is the reason to
choose RemapWrap and it is not a trial.

## Paid

A licence key unlocks:

- the surface following your foreground window
- artwork on a key instead of a label
- live audio meters
- more than two phones at once
- use inside a business, school, or other organisation

## What a key is

A key is a signed statement, checked on your own computer. There is no
account, no activation call, and no server that can turn it off. A key with
no expiry date **never expires** — that is what the code does today
(`licence.js`, `read()`), and if you sell "lifetime" that is the promise
you are already keeping.

If we stopped trading tomorrow, every key already issued would keep working
on every machine it is on.

## ▶ THE DECISION — per person, or per machine?

Your code does not currently limit installs at all: the same key works on
every PC you enter it on, and `/licence/remove` takes it off one machine so
it can go on another. A buyer who reads that will conclude the key is
theirs to move, and they will be right.

**Recommendation: say it is per person, for personal use, on any machine
they personally use.** Reasons:

- It matches what the software already does, and terms that contradict the
  software are worse than no terms.
- Enforcing per-machine would require an activation server, which destroys
  the "works on a plane, never phones home" property that is doing real
  work for you in the privacy notice.
- The people who would abuse it are the people who would not have paid.

Then a separate, more expensive **organisation licence** covers use inside
a company, school, or clinic, and that is where per-seat counting belongs —
because organisations expect to count seats and will ask you for the number.

**Pick one and this paragraph gets written accordingly:**

- [ ] Per person — one buyer, any machine they personally use *(recommended)*
- [ ] Per machine — one PC per key, others need their own
- [ ] Something else

## Refunds

**Suggested: thirty days, no questions.** RemapWrap is free until somebody
chooses to pay, so anyone buying has already used it. A refund request
means the paid features did not do what they expected, and arguing about
that costs more than the refund.

## What we do not promise

RemapWrap is provided as it is. It presses keys on your computer, and you
are responsible for what those keys do — if you bind a key to something
destructive and press it, that is not a defect.

We do not promise it works with any particular program, that any planned
feature will arrive, or that a future version keeps any feature this one
has. Where the law gives you rights as a consumer, nothing here removes
them.
