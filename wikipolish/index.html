HOW IT WORKS

LIVE ARTICLE TEXT

Pulls the current text straight from the Wikipedia API, so you're reading the article as it stands right now.

REAL GRAMMAR CHECKING

Runs the text through LanguageTool rather than guessing, and shows each issue where it occurs.

BUILT FOR FIRST EDITS

Language fixes are the safest way into editing — uncontroversial, easy to justify, and genuinely useful to the encyclopedia.
