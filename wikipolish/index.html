WikiPolish

Grammar scout for Wikipedia.

PlatformBrowser
InstallNone
ReadsWikipedia API
ChecksLanguageTool

What it does

The hardest part of becoming a Wikipedia editor is finding a first edit you are sure about. Point WikiPolish at an article and it pulls the current text straight from the Wikipedia API, runs it through LanguageTool, and shows each language problem where it occurs.

Language fixes are the safest way in: uncontroversial, easy to justify, and genuinely useful to the encyclopedia.
